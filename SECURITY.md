# Security

Plume runs the `claude` command line and reads and writes files on your disk,
so security matters. If you find a way for a book, a bible entry, an imported
file or an AI reply to read or write outside the book folder, run commands, or
leak a secret entry to the AI, please report it privately:

- use **Report a vulnerability** on the repository's Security tab, or
- contact the maintainer through their GitHub profile.

Please don't open a public issue for it. You'll get an answer within a week.
