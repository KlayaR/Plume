# Code of conduct

Plume follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, critique work and not people, and keep
discussions about Plume. Harassment, insults and personal attacks are not
welcome and lead to removal from the project.

To report a problem, open a private security advisory on the repository (see
`SECURITY.md`) or contact the maintainer through their GitHub profile.
